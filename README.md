# FutureSync — React + TypeScript

This is the renewed FutureSync frontend based on the supplied design reference.

## Tech
- React
- TypeScript
- Vite
- React Router
- CSS
- Lucide React icons

## Run in VS Code

1. Extract the ZIP.
2. Open the `FutureSync_TS` folder in VS Code.
3. Open Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost address shown by Vite.

## Included pages

- `/` — FutureSync landing/home page
- `/login` — Login page
- `/signup` — Signup page
- `/dashboard` — Logged-in dashboard
- `/goals`
- `/tasks`
- `/habits`
- `/analytics`
- `/simulator`
- `/ai`

Login and signup are frontend demo authentication for now. The user session is stored in browser `localStorage`, so a backend/database is not required yet.
